# 大模型（LLM）的记忆（Memory）技术研究地图

> 按存储机制与持续时间梳理写入、读取、更新、遗忘和治理证据

[在线阅读](https://linwei-chen.github.io/llm-memory-research-atlas/) · [综合报告](docs/REPORT.md) · [浏览结构化数据](https://github.com/Linwei-Chen/llm-memory-research-atlas/blob/main/atlas.json)

大模型记忆不是单一组件，而是分布在权重、激活与上下文、外部索引、智能体管理层和用户状态层的一组可寻址状态。地图首先按主要技术贡献归入唯一机制路线，再按状态预期持续时间定位；评测、安全与治理作为主贡献路线单列，用于显式呈现失败、污染、隐私和删除证据。

## 路线导航

| 路线 | 主要关注点 |
|---|---|
| 参数记忆与知识修改 | 知识或经验进入模型权重、适配器或可路由参数模块，并通过编辑、持续学习或反学习改变长期行为。 |
| 上下文与隐状态记忆 | 用提示上下文、注意力/KV、循环隐状态、摘要或可学习压缩保存当前会话与长序列状态。 |
| 外部检索与非参数记忆 | 把事实、文本或历史状态放在模型外部，以稠密/稀疏检索、近邻或结构化索引在生成时读取。 |
| 智能体记忆管理 | 智能体主动选择经历，执行写入、链接、反思、巩固、检索和删除，以支持长程任务与经验复用。 |
| 个性化与用户长期记忆 | 跨会话维护用户事实、偏好、关系与变化历史，强调一致性、更新、适度遗忘和用户控制。 |
| 评测、安全与治理 | 主要贡献是定义测量范式、揭示失效、攻击或隐私风险，或验证更新、删除和遗忘是否真正发生。 |

## 如何阅读

1. 打开[在线地图](https://linwei-chen.github.io/llm-memory-research-atlas/)，先从“路线 × 层级”总览判断领域结构。
2. 用关键词和出版状态缩小范围，再点击聚合节点比较同一分支中的工作。
3. 进入详情页，按“问题—机制—证据—局限—启示—来源”下钻到单项工作。
4. 需要完整论证时，继续阅读[综合报告](docs/REPORT.md)与[检索与证据审计](docs/SEARCH_AUDIT.md)；需要二次分析时使用 `data/` 导出。

页面不依赖服务端。克隆仓库后可直接双击 `index.html` 离线阅读；论文原文、代码和数据集等外部链接需要联网。

## 研究范围与证据边界

覆盖从奠基工作到 2026-08-11 的大模型参数、上下文、外部、智能体与用户记忆，以及直接评测其能力与风险的工作；正式同行评议优先，高相关预印本单列。排除只有词面重合、无状态管理贡献的普通 RAG 应用、缓存或通用微调。‘全面’表示声明范围内的多源检索与证据饱和，不表示穷尽未公开系统和全部长尾论文。

地图把出版状态、阅读优先级、证据质量和展示层级分别记录，避免把“已发表”“重要”“证据强”或“工程成熟”混为一谈。详情页中的机制图是依据文字证据绘制的解释性示意，不替代原论文图表或独立复核。

## 项目文件

- `index.html`：交互式研究全景、路线说明、时间线与完整索引。
- `paper.html?id=...`：每项工作的机制、证据、局限和一手来源详情。
- `atlas.json`：人工维护的结构化研究真源。
- `docs/REPORT.md`：领域综述、关键分歧、时间线与开放问题。
- `docs/SEARCH_AUDIT.md`：检索范围、纳排规则、覆盖限制和反证记录。
- `data/papers.json`、`data/papers.csv`、`data/references.bib`：便于阅读、分析与引用的导出。
- `planning/` 中公开的账本文件：范围合同、查询、筛选和核心主张的可追溯记录。

## 数据更新与复核

网页和数据导出由 [`build-research-atlas`](https://github.com/Linwei-Chen/build-research-atlas) 从 `atlas.json` 确定性生成。更新记录后，应重新编译并执行严格验证与真实浏览器回归；不要直接改写 `data/` 中的派生文件。

这是一份有明确截止日期和纳入边界的研究综述，不声称覆盖互联网上的全部长尾资料。若发现题名、状态、链接或证据表述需要修正，欢迎在仓库中提交问题并附一手来源。
